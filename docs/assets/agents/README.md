# Coding-agent logos

Marks shown in the agent logo row of the top-level README. All six come from
[Simple Icons](https://simpleicons.org) (v16.36.0, CC0 1.0), reduced to a single
`<path>` and filled with the brand colour where the brand mark is not black
(Claude, Gemini) or a neutral grey (`#8B949E`) that stays visible on both GitHub
light and dark themes. Codex has no mark of its own, so it uses the OpenAI mark.

| Agent | File | Icon | Vendor source recorded by Simple Icons |
|---|---|---|---|
| Claude Code | `claude-code.svg` | Simple Icons `claude` | https://claude.ai |
| Codex | `codex.svg` | Simple Icons `openai` | https://openai.com/brand |
| Cursor | `cursor.svg` | Simple Icons `cursor` | https://cursor.com/brand |
| Gemini CLI | `gemini-cli.svg` | Simple Icons `googlegemini` | https://gemini.google.com |
| opencode | `opencode.svg` | Simple Icons `opencode` | https://github.com/anomalyco/opencode/blob/1251a870cb384543c150c4a72fb101b55eec971b/packages/identity/mark.svg |
| Pi | `pi.svg` | Simple Icons `pi` | https://pi.dev/favicon.svg |
